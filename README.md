# Course Design Toolkit

An interactive tool for designing effective online learning experiences, based on five core principles of intentional course design.

## 🎯 The Five Principles

1. **Design Learning Journeys** — Not content collections
2. **Align Outcomes, Activities & Assessments** — Explicit constructive alignment
3. **Chunk for Independent Learning** — Interactive, structured, digestible
4. **Design Engagement Intentionally** — Don't assume participation
5. **Account for Total Learning Time** — Beyond watching and reading

## 🚀 Quick Start

### Option 1: GitHub Pages (Recommended)

1. Fork this repository or push it to your own GitHub account
2. Go to **Settings** → **Pages**
3. Under "Source", select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save**
6. Your site will be live at `https://yourusername.github.io/course-design-toolkit/`

### Option 2: Open Locally

Simply open `index.html` in any modern web browser. No server required.

### Option 3: Any Static Host

Upload the `index.html` file to any static hosting service:
- Netlify (drag & drop)
- Vercel
- Cloudflare Pages
- Amazon S3
- Any web server

## ✨ Features

- **Explore Mode**: Learn each principle in depth with expandable sections
- **Audit Mode**: Track your course against 30+ design criteria
- **Progress Saving**: Your checklist progress saves automatically in your browser
- **Mobile Responsive**: Works on all device sizes
- **No Dependencies**: Single HTML file, no build step required

## 🛠 Customisation

The toolkit is contained in a single HTML file for simplicity. To customise:

1. Edit the `principles` array in the JavaScript section to modify content
2. Adjust colours by changing the `color` and `lightColor` properties
3. Add new checklist items or reflection questions as needed
